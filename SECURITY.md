# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting Vulnerabilities

If you discover a potential security issue or vulnerability in ZeroTask:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately to the maintainers via GitHub Security Advisories or by contacting the team directly.
3. Include detailed steps to reproduce the issue, along with environment details (Node.js version, OS).

We will acknowledge receipt within 48 hours and coordinate a fix and release.

## Supply Chain Security Guarantee

ZeroTask is engineered with **0 third-party runtime dependencies**.
As a result, ZeroTask has 0 transitive supply chain attack surface. All code is audited and contained entirely within the repository.
